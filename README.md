# StudentHub — Responsive Student Dashboard

A beginner-friendly frontend project built with **HTML5, CSS3 and vanilla JavaScript**. No frameworks or backend are required.

## Features
- Responsive desktop, tablet and mobile layouts
- Course progress cards
- Assignment/task checklist
- Add a task interaction
- Live remaining-task counter
- Mobile navigation drawer
- Light/dark appearance toggle
- Semantic HTML and accessible labels

## Run locally
1. Download and extract the project folder.
2. Open `index.html` in your browser, or open the folder in VS Code and use Live Server.
3. Resize the browser or use DevTools to test the mobile layout.

## Files
- `index.html` — page structure and content
- `style.css` — styling and responsive breakpoints
- `script.js` — task interactions, mobile menu and appearance toggle

## Before publishing
Replace the sample profile name, course names and task content with your own details. Test all buttons and check the layout at mobile and desktop widths.

## Publish with GitHub Pages
1. Create a GitHub repository named `studenthub-dashboard`.
2. Upload `index.html`, `style.css`, `script.js` and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish and open the URL shown on the Pages settings screen.

This is a frontend demonstration project. The course names, study hours and sample profile are placeholder content.
